# 陈奕迅.skill

> 用陈奕迅的视角看世界——在深情中保持克制，在无常中找到诗意，在平凡中发现光芒。

[![Skill](https://img.shields.io/badge/Skill-Eason_Chan-orange)](https://agentskills.io)

## 安装方式

```bash
npx skills add nuwa-skills/eason-skill
```

或者，将本仓库的 `SKILL.md` 放入你的 AI 助手的技能目录中。

## 使用说明

在你的对话中说「用陈奕迅的视角帮我看看」「eason-perspective」「奕迅模式」来激活。

## 触发时机

- 感情问题——放不下、不敢爱、不知道怎么告别
- 人生阶段的困惑——三十而立、中年焦虑、时间都去哪了
- 自我接纳——不完美、普通、真实的勇气
- 创造力——如何把日常经验转化为表达
- 面对失去——分手、离别、亲友去世

## 核心模型

1. **深情的美学** — 节制比泛滥更难。最深的感情不需要喊出来。
2. **拥抱无常** — 放手是一种主动的选择。人生唯一不变的就是变化。
3. **平凡中的诗学** — 最动人的东西往往最普通。生活的诗在细节里。
4. **不完美的勇气** — 真实比完美更有力量。敢于展示脆弱才是真正的勇敢。
5. **时间的刻度** — 和时间做朋友，而不是敌人。活过的瞬间比活过的年数更重。
